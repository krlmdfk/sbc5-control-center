# SBC5 Control Center 2.8.25

## English

Public release of SBC5 Control Center 2.8.25 for Raspberry Pi 5 and Home Assistant OS.

### Highlights

- Active Cooler control with Adaptive PWM and local AI Cooling.
- CPU/OC and GPU/V3D/ISP profiles with boot verification.
- Raspberry Pi 5 system, power, PMIC, storage, network and firmware diagnostics.
- Managed `config.txt` workflow with backup, validation, rollback and restart protection.
- Mobile-first Lovelace cards with collapsible AI, CPU-core and update sections.
- Local package update pipeline with SHA-256 verification and Restart Manager.
- Semantic CPU-profile restart guard preventing false host-restart requests caused only by version comments.

### Related repository

The optional HACS companion integration is published separately:
https://github.com/krlmdfk/sbc5-control-center-integration

The HACS integration requires the SBC5 Control Center App/runtime to be installed and running.

See `CHANGELOG.md` for release history and `DOCUMENTATION.md` / `docs/QUICK_SETUP.md` for current documentation.

## Polski

Publiczne wydanie SBC5 Control Center 2.8.25 dla Raspberry Pi 5 i Home Assistant OS.

### Najważniejsze elementy

- Sterowanie Active Coolerem z Adaptive PWM i lokalnym AI Cooling.
- Profile CPU/OC oraz GPU/V3D/ISP z Boot Verification.
- Diagnostyka systemu Raspberry Pi 5, zasilania, PMIC, storage, sieci i firmware.
- Zarządzany `config.txt` z backupem, walidacją, rollbackiem i ochroną restartów.
- Mobilne karty Lovelace ze zwijanymi sekcjami AI, rdzeni CPU i aktualizacji.
- Lokalny pipeline aktualizacji z weryfikacją SHA-256 i Restart Managerem.
- Semantyczna ochrona restartu profilu CPU eliminująca fałszywe restarty hosta spowodowane wyłącznie zmianą komentarza wersji.

Historia zmian znajduje się w `CHANGELOG.md`, a aktualna dokumentacja w `DOCUMENTATION.md` i `docs/QUICK_SETUP.md`.
