# SBC5 Control Center 2.8.27

## English

Dependency documentation release: clearly documents the required SBC5 App/runtime and the Mushroom, card-mod and ApexCharts Card frontend dependencies for the complete Lovelace dashboard. No cooling, AI, CPU/GPU or boot-configuration logic changes.

### Required components

- SBC5 Control Center App/runtime
- native SBC5 Control Center Home Assistant integration
- complete Lovelace dashboard: **Mushroom**, **card-mod**, **ApexCharts Card**

### Restart

Restart Home Assistant after installation. A Raspberry Pi host restart is not required by this documentation/dependency release.
