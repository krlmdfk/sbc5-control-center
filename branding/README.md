# SBC5 Control Center branding assets

Brand identity revision: **2.6.19**.

The public project brand is **SBC5 Control Center**. The subtitle **“for Raspberry Pi 5”** is a compatibility statement and must remain visually subordinate to the project name.

The artwork in this directory is original project artwork generated for this project. It does not reproduce the official Raspberry Pi raspberry logo. The board/cooling imagery is illustrative and is not an official Raspberry Pi product photograph or brand asset.
