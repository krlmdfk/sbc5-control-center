# SBC5 Control Center — Discoverability & Search Coverage

SBC5 Control Center is a Raspberry Pi 5 control, cooling, monitoring, diagnostics and optimization platform for Home Assistant OS. This page describes the real capabilities of the project in language that users are likely to search for on GitHub, Google, Bing, DuckDuckGo, HACS and other developer or smart-home discovery surfaces.

The terms below describe supported project functionality. They are intentionally grouped by use case instead of being presented as an artificial keyword list.
