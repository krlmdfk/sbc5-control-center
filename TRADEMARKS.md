# Trademarks and project identity

## Project identity

The public-facing project name is **SBC5 Control Center**. The compatibility subtitle is **for Raspberry Pi 5**.

The project intentionally separates its own brand from third-party platform names. Public repository names should use the SBC5 brand, for example `sbc5-control-center-app` and `sbc5-control-center-bridge`.

## Raspberry Pi

**Raspberry Pi is a trademark of Raspberry Pi Ltd.**

The words “Raspberry Pi 5” are used only in a referential compatibility sense: to identify the genuine hardware model the software is designed to work with. The Raspberry Pi name must remain less prominent than the SBC5 Control Center project name in public branding.

SBC5 Control Center does not use the official Raspberry Pi raspberry logo as part of its brand. The project illustration is an original, stylized board-and-cooling graphic and is not an official Raspberry Pi brand asset or product photograph.

SBC5 Control Center is not affiliated with, endorsed by, sponsored by, or an official product of Raspberry Pi Ltd.

Current Raspberry Pi trademark guidance: https://www.raspberrypi.com/trademark-rules/

## Home Assistant

SBC5 Control Center is an independent third-party project for Home Assistant OS. It is not an official Home Assistant or Open Home Foundation component and is not endorsed or sponsored by them. The project does not claim ownership of Home Assistant names, logos or other brand assets.

## Legacy technical identifiers

Identifiers such as `rpi5_control_center_bridge`, `rpi5_fan_manager`, `sensor.rpi5_*`, package paths and storage directories remain in the codebase for backward compatibility. They are technical API/storage identifiers and not the public project brand. Renaming them would break existing automations, entity registries, dashboards and stored state.
