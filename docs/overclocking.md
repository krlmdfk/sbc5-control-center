SBC5 Control Center provides managed CPU/OC and GPU/V3D/ISP profiles for Raspberry Pi 5 together with boot verification, runtime reconciliation and restart awareness.

- CPU performance profiles
- per-core CPU telemetry
- managed `arm_freq` changes
- GPU/V3D/ISP profiles
- boot configuration tracking
- restart awareness after boot-level changes
- profile state synchronization
- temperature, power and throttling verification after changes
