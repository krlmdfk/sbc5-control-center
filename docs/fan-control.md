# Raspberry Pi 5 Fan Control for Home Assistant

SBC5 Control Center provides Raspberry Pi 5 Active Cooler and PWM fan control directly alongside Home Assistant OS telemetry and diagnostics.

## Supported capabilities

- Active Cooler management
- PWM fan control
- PWM-to-RPM calibration
- fan speed and RPM monitoring
- automatic, hybrid and manual control modes
- custom temperature fan curves
- Adaptive PWM corrections
- temperature target and hysteresis handling
- safe slew limiting for smooth fan-speed changes

SBC5 is useful for users looking for **Raspberry Pi 5 fan control in Home Assistant**, **Active Cooler monitoring**, **PWM fan control**, **RPM monitoring**, or **temperature-based cooling**.
