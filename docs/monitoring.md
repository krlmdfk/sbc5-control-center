# Raspberry Pi 5 Monitoring & Diagnostics for Home Assistant

SBC5 Control Center exposes Raspberry Pi 5 telemetry and diagnostics in a Home Assistant-oriented interface.

## Monitoring areas

- CPU temperature, clock and per-core telemetry
- GPU/V3D/ISP state and profiles
- fan PWM and RPM
- power and PMIC information
- memory and storage status
- throttling state
- network information
- firmware and bootloader diagnostics
- configuration and runtime health

SBC5 is intended for users searching for **Raspberry Pi 5 monitoring in Home Assistant**, **CPU/GPU monitoring**, **temperature monitoring**, **hardware diagnostics**, **system telemetry** and **Raspberry Pi dashboard** capabilities.
