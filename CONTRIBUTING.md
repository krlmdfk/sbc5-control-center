# Contributing to SBC5 Control Center

Dziękujemy za zainteresowanie rozwojem projektu.

## Zgłaszanie błędów

Do zgłoszenia dołącz:

- wersję SBC5 Control Center,
- wersję Home Assistant,
- model zasilacza i chłodzenia, jeśli ma znaczenie,
- fragment logu obejmujący problem,
- kroki prowadzące do odtworzenia błędu,
- oczekiwane i faktyczne zachowanie.

Nie publikuj tokenów, haseł ani innych danych uwierzytelniających.

## Pull requests

- utrzymuj zmiany możliwie małe i tematyczne,
- nie zmieniaj identyfikatorów encji bez potrzeby,
- aktualizuj dokumentację i `CHANGELOG.md`,
- przed wysłaniem zmiany upewnij się, że walidacja projektu kończy się powodzeniem,
